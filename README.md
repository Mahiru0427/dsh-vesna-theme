# 薇斯纳主题 · 日常按钮与全窗口壁纸更新（0.2.1）

为 DeepSeek Harness Desktop 制作的独立主题插件。采用用户认可的双手托脸、微瘦脸、金线花框壁纸，以及六款卡通表情。浅色使用奶白遮罩，深色使用海军蓝遮罩；图片不需要联网加载。

## 使用范围

- 设置 → 通用中增加「薇斯纳主题」，提供春日浅色、夜宴深色、跟随系统和默认配色。
- 通过官方 ThemeRuntime 的 token 覆盖接口调整侧栏、阅读区域、输入区域、按钮、菜单、链接、代码块等使用平台配色变量的组件。
- 明暗偏好由 DSH 自己保存；角色配色、壁纸和表情开关单独保存在本机。恢复默认会撤下插件配色和壁纸，隐藏表情。支持读取第一版的保存记录。
- 不接触模型、凭据或聊天文件。不替换程序安装文件。
- 日常表情已接入侧栏「新会话」、主页欢迎区和「发送消息」按钮；文字、快捷键、禁用状态及原有事件处理保留。发送按钮保留小箭头，停止和删除等控件保留原生图标。设置卡片同时提供预览及壁纸/表情独立开关。
- 同一张壁纸铺满整个窗口。左栏、顶部应用控制栏和右侧工具栏采用 12px 高斯模糊及半透明遮罩；输入框、设置卡片和内容工具保持可读背景。遵循系统降低透明度偏好。

## 安装

已在本机正在运行的 Desktop **0.2.0-rc.2** 中实际安装并启用。已生成 `lib/client.js`，无需自己编译。

1. 从本仓库的 **Releases** 下载 `dsh-vesna-theme-0.2.1.tgz`。
2. 打开 **DeepSeek Harness Desktop → 插件 → 添加插件**，选择下载的安装包。
3. 安装后点击「立即启用」。
4. 到 **设置 → 通用设置 → 薇斯纳主题** 选择配色、壁纸和表情开关。

本机已经完成这些操作，无需重复安装。当前使用夜宴深色，壁纸与表情开启。

本机 Desktop 版本不允许通过 `dsh plugin --profile desktop` 管理，安装应走应用插件管理页面。不要用旧版全局 CLI 修改 Desktop 配置。

## 恢复与卸载

临时恢复：主题设置点「默认配色」。恢复后仍保留当前原生明暗模式。

卸载：先恢复默认，再到 Plugins 禁用或移除 `dsh-vesna-theme`，退出并重新打开 Desktop。本机的角色主题选择记录保留，再次安装会沿用。插件选择与原生明暗模式是分别保存的。

## 最新界面调整（2026-10-08）

- 只有窗口最外层铺壁纸，聊天视口及消息气泡透明，避免重复画面。
- 侧栏、顶部及右栏模糊8px；输入框10px，保留半透明底色保证文字可读。
- 添加文件/调用指令菜单使用不透明的主题底色，避免聊天正文透入菜单。
- 招呼语为「找我什么事呀，亲爱的朋友~」，与主页输入区靠左；欢迎表情84px。原DS图标及预览标签隐藏。
- 新会话使用36px脸部头像、48px高按钮；发送使用40px脸部与爱心头像、88×46px按钮。通过CSS裁切原画减少身体及留白，头像旁保留文字，没有箭头遮住爱心。两处悬停或键盘聚焦显示80px完整表情，移开、失焦或按键后收起。
- 添加文件保留原生加号；好的回答/有问题的回答保留原生评价图标。悬停或键盘聚焦时，分别显示64px的读书/点赞/疑惑表情。添加菜单打开时隐藏文件入口的表情。
- 六张表情均有日常位置：比耶→新会话；思考→欢迎；读书→文件入口悬停；疑惑→负面评价悬停；点赞→正面评价悬停；爱心→发送。
- 默认配色或关闭表情后恢复原生功能控件；按钮事件和可访问名称保留。
